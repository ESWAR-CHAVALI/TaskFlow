# TaskFlow 🚀

A full-stack collaborative Team Task \& Issue Tracker inspired by Jira and Linear. Built from the ground up over a 30-day challenge with daily commits to master enterprise full-stack development.

## 🛠️ Tech Stack

* **Backend:** Java 21, Spring Boot 3, Spring Data JPA, Spring Security, JWT
* **Frontend:** React, Vite, Tailwind CSS, Axios
* **Database:** MySQL 9.1
* **Tools:** Maven, Git, GitHub, Postman, Docker
